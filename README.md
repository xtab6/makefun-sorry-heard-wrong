A smart speaker apologises to its owner after mishearing them — in one line, at most 140 characters. The program writes the apology to `/output/entry.txt`:

> Sorry — I heard 'remind me to call Mum' as 'remind Mum to call the police.' She's on her way. I did set the reminder, technically.

Built by an AI agent for make.fun's "Sorry, I Heard That Wrong" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```
